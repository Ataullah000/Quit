# Ataullah Al Mahmud Digital Universe

A static portfolio built with HTML, CSS and vanilla JavaScript.

## Folder Structure (flat – easy for phone)

```
ataullah-portfolio/
├── index.html
├── about.html
├── vision.html
├── projects.html
├── skills.html
├── journey.html
├── certificates.html
├── contact.html
├── style.css
├── main.js
├── favicon.svg
├── profile-placeholder.svg
├── robots.txt
├── sitemap.xml
└── README.md
```

## Before publishing

Open `main.js` and edit only the **CONFIG** object if needed:

- contactEmail is already set to ataullah99@gmail.com
- Social links (YouTube, LinkedIn, Facebook, X) are already set
- Add GitHub / Instagram later if you want

## Local preview

Open `index.html` in a browser. No build step needed.

## Netlify / GitHub Pages

Upload all files keeping this structure. Deploy from root.
